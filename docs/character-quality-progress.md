## کار جلسهٔ ۲ (همه با آزمون واقعی)

### ۱) تعمیم هارنس هندسی V3 — پوشش ترکیب‌ها
ماتریس **بدنه(2)×سلاح(2)×کلیپ(4)** (Male/Female × sword/claymore × idle/walk/guard/attack[2h]) در
۱۲۰Hz + زیرگام‌های swept + متریک **minBladeClearance** و byZone/sweptOnly.

  مجاز دسته×دست را نقض گزارش می‌کرد (qa-run: انگشتان → دستِ همان سمت)
- نتیجهٔ ثبت‌شده با mount جدید: همهٔ ترکیب‌ها صفر نقض — کمینهٔ clearance ۳۵٫۲cm (female×clay idle)

### ۲) چنگ دو‌دستی grip2 — بنچمارک head-to-head و انتخاب عددی
دو حل‌کننده روی همان هارنس (tests/offhand-grip.test.ts)، همان معیار (رساندن دست چپ به grip2 + کشش):
| کلیپ | TwoHandIK تحلیلی (۲مفصلی) | OffHandGrip CCD (با ترقوه) |
|---|---|---|
| idle | ✗ 18.7cm (خارج بُرد، فقط clamp) | **0.0cm** |
| walk | ✗ 18.6cm | **0.3cm** |
| guard | ✗ 11.0cm | **0.0cm** |
| attack2h | 0.2cm ✓ | 0.3cm ✓ |
| کشش زنجیره | 0% | 0% |
| + AntiClip فعال | بدون جنگ ✓ | بدون جنگ ✓ |

⇒ **OffHandGrip (CCD) فعال شد** (engine: بعد از AntiClip — وابستگی یک‌طرفه کلیپ→سلاح→دست دوم،
بدون حلقهٔ بازخورد). TwoHandIK به‌عنوان ماژول کتابخانه‌ای تست‌شده می‌ماند (تست واحد خودش سبز است).
`grip2Target` فرزند گروه سلاح در universal ساخته می‌شود؛ armBones حالا clavicle هم می‌دهد.
- **کشف ثبت‌شده**: کلیپ حملهٔ 1H × سلاح 2H نامعتبر است — grip2 تا ~۱۸cm از بُرد دست چپ بیرون می‌زند
  (تست «INVALID» — موفق گزارش نشده؛ موتور سلاح دو‌دست را به attack2h می‌فرستد)
